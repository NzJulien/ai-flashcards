# AI Flashcard Generator

> Paste any text, topic, or notes and instantly generate smart flashcards using Claude AI.

## Live Demo
https://nzjulien.github.io/ai-flashcards

## Features
- Generate 3-30 flashcards from any text or topic
- Study mode with flip cards (click or Space to flip)
- Browse mode with expandable grid
- Track known vs still-learning cards
- Difficulty levels: Beginner / Intermediate / Advanced
- Card types: Q&A, Definition, True/False, Fill-in-the-blank, Mixed
- Multi-language support
- Export to JSON or CSV
- Keyboard shortcuts: Arrow keys to navigate, Space to flip, Y/N to mark

## Stack
- Vanilla HTML/CSS/JS
- Claude claude-sonnet-4-6 API
- Zero dependencies
